# Mandatory Rule: Single Screen View — No Duplicate Actions or Duplicate UI Blocks (Rule 17)

> **ZERO TOLERANCE**:
> Within the same Screen, Page, Workspace, Modal Dialog, Drawer, or Inspector Panel:
> 1. **SINGLE SOURCE OF ACTION**: Every capability, action, or tool must have **EXACTLY 1 CONTROL POINT**.
> 2. **STRICTLY PROHIBITED**: Rendering multiple buttons, floating controls, or duplicate tabs performing the same action in the same view (e.g. "Save" in top navbar AND canvas toolbar; multiple "Clear Logs" buttons in one panel).
> 3. **ELIMINATE DUPLICATES**: When duplicate action triggers are identified, immediately remove the duplicate and preserve only the primary control location.
